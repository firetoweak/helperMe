# 项目原则

1. **内部相信契约**  
   外部边界精确校验输入，只转换语义明确的已知错误；内部契约违规、持久化损坏和未知异常必须原样暴露，不得被降级为普通失败或可继续状态。

2. **不兼容旧设计**  
   本项目不为已经废弃的设计保留兼容层。采用新设计时，应删除旧路径和临时双轨，不以兼容、兜底或迁移便利为由长期积累技术债。

3. **Runtime 不做语义判断**  
   Runtime 只负责确定性的事实归约、调度、不变量和安全边界。凡是涉及目标理解、事实含义或下一步行动的语义判断，必须显式交给模型。Agent 的脚手架不能比模型更聪明，也不能在隐藏路径中越界替模型决定。

4. **复杂度由一个人掌控**  
   HelperMe 服务于一个人，不为未知用户建设通用框架。系统可以持续增加能力，但整体复杂度必须仍由一个人理解、解释和控制。
