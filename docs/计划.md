## Runtime 性能后置

下一步单独设计 checkpoint 增量重放，不并入第 2 章摘要：

- Journal 提供廉价的当前位置，例如 `sessions.last_sequence`；

- Level 2 摘要仍只是模型上下文投影，绝不写回 Journal 当事实或 checkpoint。

完成 checkpoint 设计并取得测量数据后，再评估 SQLite 的 `synchronous=FULL` 与每操作新建连接；不提前改变持久化保证或引入连接复用。


## 后到 UserMessage 调度

2026-08-27 已落地。规范见 [Runtime 状态推进模型](架构/Runtime状态推进模型.md) 第 6 节。

没有独立 Interrupt Event。运行中与空闲输入都是 `UserMessageReceived`。归约两条机械规则：

1. 消息立刻入账；若签发 Step 的冻结视图早于这条消息，且已有未终态 Attempt，先等这批 Outcome，再把它当作可执行的 `next_trigger`。未派发（含待授权）不挡。同一轮已签发 Command 要跑完，不是再开一轮。
2. 签发冻结（`observed_journal_position`）早于这条消息的 `decision_on_outcome` 组，闭合后不再单独要 Step。下一次决策的 trigger 就是这条 UserMessage。后到相对冻结切面，即使消息写在该 `StepCommitted` 之前。

下一步：Cancel / 杀进程 /通用 Interrupt 协议。

## 第 1 章 · get_changes

2026-08-23 完成。`get_changes` 是工作区快照证据，不替模型或 Judge 判断任务完成。

- tracked 正文统一读取 `HEAD → 最终工作树`，覆盖 staged 与 unstaged；

- 契约测试位于 `tests/tools/test_get_changes.py`。

## 第 3 章 · 长任务

2026-08-24 结论：Kanban 与独立 Audit 放在同一专题设计。现有简单任务继续依靠「普通工具 Outcome 唤醒下一 Step；模型不再调用工具后进入 `WAITING(user_message)`」自然停机。

当前 `LifecycleIntent.COMPLETE` 和 Finalization Barrier 只是已实现并有测试覆盖的基础设施。生产 Channel 是持续 Session，不调用 `finalize()`；不在长任务专题前单独补触发。未来明确有界的 SubAgent 或一次性后台执行可以显式复用终态协议。

## 第 4 章 · Automation

Agent 不只在同步对话里跑。

端口是 `automation`：外部按策略醒来，向**已经选定**的 Session 追加事实。Channel 或 Automation 选 identity；Assistant 接收并 wake；Runtime 每次只推进一个 Step。

| 能力  | 接法                           | 第一刀                     |
| --- | ---------------------------- | ----------------------- |
| 定时  | 时间策略追加 Timer 一类事实            | 延迟或 cron 唤醒一条已有 Session |
| 监听  | 监听策略追加外部变化一类事实               | 文件或外部信号变化后醒来            |
| 后台  | 没有前台 Channel 时仍推进同一条 Session | 进程里没有人盯着也能 `advance`    |


## 第 5 章 · SubAgent

SubAgent 是**普通独立 Session**。委派和回收属于 `assistant`，用因果 Event 表达；Runtime 不增加 `parent_session_id`、`agent_type`。

```text
父 Session 决定委派
        ↓
Assistant 创建子 Session（同一套 create / advance / recover）
        ↓
子 Session 自己的 Journal、工具、判定
        ↓
结果作为事实回到父 Session，父再决策
```

具体待后续设计

## 第 6 章 · Memory

从 Journal / Artifact 提炼带来源的知识，在 Decision Context **开始时冻结**检索结果。Journal 仍是嘈杂经历；Memory 是值得复用的派生，必须能指回事件。

```text
Journal / Artifact
        ↓
提取（带来源）
        ↓
存储与检索
        ↓
Step 开始时写入冻结 Decision Context
```
