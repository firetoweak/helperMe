# 架构总览

HelperMe 的运行事实在 Journal 里。模型看到的对话、人看到的一轮问答，都是投影。

> **Event 是唯一持久执行事实，State 是事件归约结果，Step 是决策推进单元，Command 是外部副作用闭环，Turn 是人类交互投影。**

完整决策见 [Runtime 状态推进模型](Runtime状态推进模型.md)。

## 分层

```text
console_chat.py
      │
helperme/channels/cli/console.py   CLI 输入、Interrupt、控制命令
      │
helperme/assistant/               决策、上下文、完成判定、驱动、装配
      │
┌─────┴─────────────┬───────────────────────┐
│                   │                       │
helperme/runtime       helperme/llm + helperme/sandbox     helperme/mcp + helperme/skills + helperme/tools
执行内核            模型接口 + 执行环境                 MCP / Skill / 文件命令
```

| 包 | 职责 | 禁止 |
|---|---|---|
| `helperme/runtime` | Event、State、Step、Command、终态 Barrier | import 其他 helperme 模块 / host / plugins / tools |
| `helperme/assistant` | 模型决策、Context、Completion、Artifact、Runtime 驱动、产品装配 | 控制台输入输出 |
| `helperme/channels/cli` | CLI 输入输出、并发 Interrupt、控制命令 | 实现模型决策或 Runtime 推进循环 |
| `helperme/llm` | 模型契约、Provider 客户端与连接配置 | import Assistant / Runtime / Sandbox / MCP / Skills |
| `helperme/sandbox` | Workspace View、权限绑定、本地环境与进程执行 | import Assistant / Runtime / Tools / MCP / Skills |
| `helperme/mcp` | MCP Registry、Client、控制面 | 把 MCP 名词写入 Runtime；遮蔽第三方 `mcp` SDK |
| `helperme/skills` | Skill 包、安装、管理与两个普通工具 | 做成第三种执行循环 |
| `helperme/tools` | ToolSpec、参数契约、执行器、管理控制请求与环境工具 | 反向依赖 Assistant / Runtime / MCP / Skills；把控制请求当 Runtime 授权 |

强制测试：`tests/architecture/test_import_boundaries.py`、`tests/architecture/test_runtime_boundaries.py`。

当前按职责分片迁移，尚未为了目录整齐一次性搬动所有稳定模块。最终目录方向见[项目架构方向](../项目架构方向.md)。


## 一次推进

```text
UserMessageReceived
  → RUNNABLE
  → Step：模型决策 + 发出 Command
  → Dispatcher 执行工具（可并行）
  → CommandOutcomeReceived
  → 需要再决策则再开 Step
  → content-only deliver → WAITING(user_message)
  → 严格收口任务可由 Judge 写请求决策的 Domain Fact
  → COMPLETED / TERMINATED 必须过 Finalization Barrier
```

Turn 结束不是 Stream 终态。人在控制台打字，只是下一条外部事实。

## 产品规则（判定）

人负责目标；模型补全判定标准；后一句默认改 inferred；只有人明确换事才改目标。聊天任务模型自己 COMPLETE 可直接收口。写文件或跑命令后要过独立 Judge。详见 [判定](判定.md)。

## 入口

```text
python console_chat.py
```

Journal：`~/.helperme/runtime_streams/journal.sqlite`。Toolset 激活由已提交的加载结果投影，Assistant ToolSurface 缓存可重建；`/new` 开新 Stream，`/resume <stream_id>` 显式恢复已有 Stream。`/stop` 写 `TerminationRequested`。
